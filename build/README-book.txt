{TITLE} — 3rd Edition
=====================================================

Contents of this folder
  {NAME}.idml   One InDesign file for the whole book ({PAGES} pages): cover, title page,
                how to use + image credits, contents, all sections, notes pages and back cover.
  {NAME}.pdf    The finished book as PDF (bookmarks; contents and chapter pages are clickable).
  Links/        All images used by the IDML. Keep this folder next to the .idml file.

Opening the IDML
  1. Unzip everything, keep Links/ beside the .idml, then open the .idml in InDesign
     (File > Open). If InDesign asks for links, point it at the Links folder once
     (Window > Links > Relink), it will find the rest.
  2. Fonts: Acumin Variable Concept, Source Serif Variable and Source Sans Variable
     (all available through Adobe Fonts).
  3. Smart Text Reflow is switched on. If any section composes slightly longer in your
     InDesign, pages are added at the end of that section automatically; check the
     page numbers in the contents page and the chapter openers before printing.

What changed in this edition
  - The word "UPDATED" was removed from every question and answer.
  - Every image (question images and summary boxes) is an anchored object set to
    "Above Line" (also the default for new anchored frames).
  - New front cover in the Surgery Bank 1 style, using the supplied artwork.
  - New section dividers: real photographs and scans (X-ray, CT, MRI, ECG, clinical
    photographs) colour-graded in each chapter colour. Sources and licences are
    listed on the "How to use this book" page and printed on each divider.
  - Sections now always open on a left-hand page (divider) facing the chapter opener;
    a ruled Notes page fills any gap.
